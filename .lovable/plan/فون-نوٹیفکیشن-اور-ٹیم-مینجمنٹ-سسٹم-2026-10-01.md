# فون نوٹیفکیشن اور ٹیم مینجمنٹ سسٹم

## حصہ 1 — فون پر نوٹیفکیشن (Push)

### کیا بدلے گا
- ایپ بند ہو تب بھی رائیڈر، دکاندار اور گاہک کو فون پر اطلاع ملے گی۔
- **رائیڈر:** نئی آفر (آواز + وائبریشن)، آرڈر اسائن، آفر منسوخ۔
- **دکاندار:** نیا آرڈر، 5 منٹ تک قبول نہ کرنے پر یاد دہانی، رائیڈر پہنچ گیا۔
- **گاہک:** آرڈر قبول، تیار، رائیڈر روانہ، ڈلیور، ریفنڈ منظور۔
- **ایڈمن/ٹیم:** پھنسا آرڈر، نئی شکایت، کیش وصولی زیر التوا۔
- پروفائل میں "اطلاعات" سیٹنگ: کون سی اطلاع چاہیے آن/آف۔
- ہر اطلاع ایپ کے اندر "اطلاعات" والے صفحے پر بھی محفوظ رہے گی (پڑھی/غیر پڑھی)۔

### آپ سے درکار
- Android/Play Store ایپ کے لیے Google Firebase کی ایک key درکار ہوگی — میں قدم بہ قدم بتاؤں گا کہ کہاں سے لینی ہے۔ ویب/PWA نوٹیفکیشن بغیر کسی key کے چالو ہو جائیں گے۔

## حصہ 2 — ٹیم اور اجازتوں کا نظام

### نئے عملے کے کردار
| کردار | کیا دیکھ/کر سکتا ہے |
|---|---|
| مالک | سب کچھ، عملہ شامل/ہٹانا |
| آپریشن مینیجر | لائیو آرڈر، ڈسپیچ، رائیڈر کنٹرول، پھنسے آرڈر |
| ڈسپیچر | صرف آرڈر اور رائیڈر اسائنمنٹ |
| سپورٹ | گاہک کی معلومات، شکایات، ریفنڈ کی *درخواست* |
| فنانس | ادائیگیاں، کیش وصولی، ریفنڈ کی *منظوری* |
| پارٹنر مینیجر | دکانیں، مینو، درخواستیں |
| رائیڈر سپروائزر | رائیڈر تصدیق، معطلی/بحالی |

- ہر عملہ ایڈمن پینل میں صرف اپنے ٹیبز دیکھے گا؛ باقی چھپے رہیں گے اور ڈیٹا بیس سطح پر بھی بند ہوں گے۔
- عملہ کو مخصوص شہر تک محدود کیا جا سکے گا۔

### عملہ کا انتظام (صرف مالک)
- "ٹیم" صفحہ: ای میل سے عملہ شامل کریں، کردار اور شہر منتخب کریں، معطل یا ہٹائیں۔

### کام کا ریکارڈ (Audit)
- ہر اہم کام خودکار محفوظ: کس نے، کب، کیا بدلا (آرڈر اسٹیٹس، رائیڈر اسائن، ریفنڈ، ادائیگی، دکان بند/کھولی، کردار تبدیلی)۔
- ریکارڈ کوئی مٹا یا بدل نہیں سکے گا۔

### دو افراد کی منظوری
- Rs 2,000 سے زیادہ ریفنڈ اور ہر وینڈر ادائیگی: ایک شخص درخواست کرے، دوسرا (فنانس/مالک) منظور کرے۔ ایک ہی شخص دونوں نہیں کر سکے گا۔

### ٹیم پرفارمنس (مالک کے لیے)
- ہر عملے کے: کیے گئے کام، پھنسے آرڈر حل کرنے کا اوسط وقت، شکایات حل کرنے کا وقت، منسوخیاں/غلطیاں۔
- آج / 7 دن / 30 دن فلٹر اور CSV۔

## ترتیب
1. ٹیم رولز + اجازتیں + ٹیم صفحہ
2. کام کا ریکارڈ + دو افراد کی منظوری
3. ایپ کے اندر اطلاعات صفحہ + ویب Push
4. Android Push (Firebase key ملنے کے بعد)
5. ٹیم پرفارمنس صفحہ، پھر مکمل جانچ

## تکنیکی تفصیل
- `app_role` enum میں نئے رول: `ops_manager`, `dispatcher`, `finance`, `partner_manager`, `rider_supervisor` (موجودہ `support`, `admin` برقرار)۔ `staff_scopes(user_id, city_id)` ٹیبل۔
- `has_permission(uid, perm)` SECURITY DEFINER فنکشن؛ متعلقہ RLS policies اور RPCs (`admin_force_assign_rider`, `admin_pay_vendor`, refunds وغیرہ) میں چیک شامل۔ پرائمری اونر تحفظ برقرار۔
- `staff_audit_log` append-only (update/delete revoke)، اہم ٹیبلز پر triggers + RPCs میں logging۔
- `approval_requests` ٹیبل + `request_approval`/`approve_request` RPCs، requester ≠ approver گارڈ۔
- `notifications` ٹیبل (realtime) + `notification_prefs`؛ order/offer triggers سے insert؛ `send-push` edge function موجودہ `device_tokens` استعمال کرے گی (Web Push VAPID + FCM v1)۔
- Capacitor `@capacitor/push-notifications` رجسٹریشن؛ موجودہ `usePushNotifications` hook اپڈیٹ۔
- AdminDashboard میں ٹیبز کی نمائش permission کے مطابق؛ نیا `TeamTab`, `TeamPerformanceTab`, `ApprovalsTab`۔
