# EasyLife — پریمیم پروڈکٹ، اکاؤنٹ اور کارٹ اپ گریڈ

Buypass AI جیسا تجربہ بنانے کا منصوبہ۔ کام تین فیز میں۔

## فیز 1 — پروڈکٹ ڈیٹیل پیج (سب سے اہم)

نیا روٹ: `/product/:id` (گروسری + بازار دونوں کے لیے ایک ہی صفحہ)۔

- بازار/گروسری کارڈ پر کلک اب **اسٹور ہوم پیج** کی بجائے سیدھا پروڈکٹ پیج کھولے گا۔
- صفحے کا ڈھانچہ (اسکرین شاٹ کے مطابق):
  - اوپر: بیک بٹن، سرچ، کارٹ آئیکن
  - بڑی امیج گیلری (سوائپ + ڈاٹس، "Item 1/5")، ریٹنگ اور Sold بیج
  - قیمت بلاک: بڑی قیمت + کٹی ہوئی MRP + `-X%` بیج
  - عنوان، یونٹ/وزن، MOQ
  - ویریئنٹ/آپشن چپس (رنگ، سائز، وزن)
  - ڈیلیوری موڈ کارڈ (رائیڈر / کوریئر، متوقع دن)
  - اسٹور کارڈ (نام، ریٹنگ، "دکان دیکھیں")
  - ٹیبز: Overview · تفصیل · ریٹنگز · ملتی جلتی اشیاء
  - نیچے چپکی ہوئی بار: **Chat · Add to Cart · ابھی خریدیں**
- "ابھی خریدیں" → کارٹ میں ڈال کر سیدھا Checkout۔

## فیز 2 — پروڈکٹ ڈیٹا کو امیر بنانا

`grocery_products` میں نئے کالم:
`images text[]`, `brand`, `sku`, `weight`, `stock_qty`, `tags text[]`, `specs jsonb`, `variants jsonb`, `rating`, `sold_count`, `delivery_days`

- ویینڈر (گروسری/بازار) کے پروڈکٹ فارم کو ملٹی امیج اپ لوڈ، برانڈ، اسپیکس، ویریئنٹس، اسٹاک کے ساتھ دوبارہ بنایا جائے گا۔
- ایڈمن گروسری ٹیب میں بھی وہی امیر فارم۔
- ریٹنگ/sold count موجودہ آرڈرز اور ریویوز سے خودکار۔

## فیز 3 — اکاؤنٹ اور کارٹ کو پریمیم بنانا

**پروفائل/اکاؤنٹ (`Profile.tsx`)**
- گرادیئنٹ ہیڈر: اوتار، نام، ممبرشپ بیج، والیٹ بیلنس
- کوئیک ٹائلز: آرڈرز، پتے، والیٹ، وؤچرز، ریفرل، سپورٹ
- آرڈر اسٹیٹس رو (زیر عمل / راستے میں / مکمل) گنتی کے ساتھ
- سیٹنگز سیکشن گروپ شدہ لسٹ کی شکل میں

**کارٹ (`CartDrawer.tsx` + Checkout)**
- ہر آئٹم: تھمب نیل، ویریئنٹ لیبل، اسٹیپر، سیو/ڈیلیٹ
- بل خلاصہ: سب ٹوٹل، ڈیلیوری، ڈسکاؤنٹ، وؤچر ان پٹ، کل
- "مزید شامل کریں" ریکمنڈیشن رو
- خالی کارٹ کی خوبصورت اسٹیٹ
