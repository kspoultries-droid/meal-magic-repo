# Operations lists
- Apply status, Karachi date boundaries and sanitized search before bounded server ranges; exact counts drive pagination so historical or active orders are not hidden by a latest-row cap.
- Preserve drafts and expanded records on background refresh, reject obsolete request results, and retain successful rows on read errors; list UX must never change authorized lifecycle actions.

# Ads
- Pick existing authorized businesses/items and derive canonical destinations; copied ad drafts never change catalog prices.
- Preview the prepared creative, verify image readability before save, retain uploaded URLs on record errors and lock duplicate submissions so upload failures cannot publish imageless ads.

# Catalog review
- Share local barcode decoding between shop setup and admin review; decoded numbers are draft evidence, never automatic photo verification or a replacement for server uniqueness.
- Advance review only after an authorized save returns a row; keep failed drafts and the selected review queue intact.
